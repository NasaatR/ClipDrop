Functional Windows foundation preview: native shelf for files, folders,
PNG/bitmap/virtual-file inputs, Unicode text and links. Multi-format drag/copy,
multi-selection, search, pins, previews, undo removal, recoverable local saves,
appearance controls and copyable diagnostics.

Download `*_windows-x64_setup.exe` (recommended) or extract the entire portable
ZIP. Both include the runtime. No subscription or account required.

Pipeline checks core recovery, native Windows clipboard/transfer formats, WPF
rendering, ZIP contents and silent installation/uninstallation. Manual external
Photoshop/Figma/browser drag compatibility is not yet verified. Unsigned preview.
See README for requirements, limits, data location and retained-cache behavior.
