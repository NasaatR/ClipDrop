Compact Downloads with predictable dismissal, plus verified library backup export.

- Downloads uses 34-DIP single-line rows with 24-DIP previews, filenames and short times; the normal window fits at least ten rows. Full path/size/time is in the tooltip. No left checkbox column or persistent bottom action bar.
- Hover/click opens; pointer leave collapses promptly, outside click and Close dismiss immediately, and a completed/cancelled transfer closes the list. No hidden click-to-latch mode. Actual OLE, menus and window movement are held safely. Main-dock collapse preferences remain independent.
- Grab any row directly. Ctrl/Shift optionally select a group; right-click offers Copy, Save to Library, Open and Show in Explorer. Double-click opens a file. Native file copies preserve originals and do not consume Library clips.
- Settings → Backups → Create backup exports the current state, including unsaved metadata, Trash, saved panels/windows, raw clipboard payloads, owned assets and style PNGs. External originals stay as path references; Chrome catalogs and orphan caches are excluded. Every copy uses a new filename and never replaces an existing file.
- Archive creation and verification run in the background with cancellation. The finished temporary ZIP must pass path/membership/length/SHA256 checks before publication. Stage 5a1 is export/verification; restore preview and conflict-safe import are next.

Chrome downloads from all save folders remain available through the bundled companion. Existing connections keep their identity. Reload the extension in chrome://extensions after updating the app. No new permissions, browser page access or clipboard monitoring.

Quit ClipDrop from the tray and install over the current version. Runtime included; unsigned Windows x64 preview. Data schema stays7 and existing settings/panels/Trash remain intact. Verification includes Core recovery/export checks, native Windows file drags and flyout behavior, background backup/cancel, published startup, Chrome native messaging and a disposable real Chrome custom-folder download. Third-party Photoshop/Figma/Pinterest gestures and physical mixed-DPI hardware remain separate manual checks.

Research references and decisions are in docs/ROADMAP.md: Apple's Dock folders, Downloads Stack for Windows Tray, DropStack and Stacky. Application code is original; no upstream source or assets copied.
