A Save-only dock and a simpler collect → select → drag workflow.

- The resting dock shows only Save and clip content. Move it from any free area. Right-click Save/free space for Library, saved panels, selection, clipboard-to-Library, settings, hide and available undo. Double-click free space opens Library. Selection-only text controls appear when needed; no permanent grip, gear, Library, panels, selection or eye buttons.
- Library intake (clipboard, file picker, external drop) saves directly to Library without automatically pinning new captures to the dock. New clips are immediately selected for a counted Drag N action. Existing pins are not removed when a duplicate is saved again.
- Checkboxes select several clips without Ctrl. Drag the counted selection control or any selected row to transfer the group. Cancel keeps clips; accepted Copy drops archive only unprotected references, retaining originals. An internal drop back into Library keeps the original clips without reimporting them.
- Library keeps useful text navigation and moves infrequent commands into More. Footer actions appear only for a selection. Compact menus remove unused icon-column space and show check states. Automatic group selection updates its action bar once per batch.
- The roadmap records an optional Send to Figma adapter based on the existing ordered helper queue and receiver. No Figma integration or helper/network startup is enabled in this release.

The installer upgrades the existing installation; quit from the tray before updating. Runtime included; unsigned Windows x64 preview. Data schema remains 5, with existing panels, Trash, styles, clipboard payloads and migration backups retained.

Mirrored monitors still share one active set. Independent set windows, backup/version UI, opt-in clipboard history and Send to Figma remain separate stages. Real physical mixed-DPI hardware and third-party app gestures retain their existing manual acceptance boundaries.
