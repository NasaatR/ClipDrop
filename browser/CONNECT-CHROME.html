📥 Your Chrome downloads, in ClipDrop

Connect once in each Chrome profile you use. Chrome chooses where files are saved; ClipDrop shows the newest completed downloads from all those locations.

  1. Open chrome://extensions in Google Chrome.
  2. Enable Developer mode in the top-right corner.
  3. Choose Load unpacked and select the chrome folder that ClipDrop just opened in Explorer.
  4. Open the ClipDrop Downloads extension popup and choose Sync now. It should say Connected.
  5. In ClipDrop, right-click the dock → Downloads. Hover the capsule and drag any file row directly into another app. Use Ctrl/Shift only when you want several files together.

The connector runs locally with no account or subscription. It shares paths and completion times for up to 200 recent finished downloads per profile; the dock shows the newest 40 available files. No website content, cookies or source URLs are sent. Incognito and unfinished or blocked downloads are excluded.

To pause, turn off Share recent downloads in the popup; this clears that profile's local list after the host acknowledges it. Removing the extension stops updates; previously received paths remain locally. Clear the browser-downloads directory in ClipDrop's data folder to remove that cache.

If the portable app was moved, use Settings → Downloads → Connect Chrome again. After updating ClipDrop, reload the extension in chrome://extensions. Chrome Web Store distribution and image-send actions are later stages.
